# AI 漫剧工坊 — 操作指南

> 版本：v1.0 | 日期：2026-10-17 | 适用：前后端分离版（frontend/ + backend/）

## 1. 启动与停止

### 一键启动（推荐）

```bash
./scripts/start.sh
```

自动执行：环境检查（ffmpeg / Redis / PostgreSQL）→ Alembic 迁移 → 拉起三组进程：

| 进程 | 地址 | 说明 |
|---|---|---|
| 前端 | http://localhost:3000 | Vite 开发服务器 |
| 后端 API | http://127.0.0.1:8000/api | 交互文档 `/docs`，健康检查 `/healthz` |
| Celery Worker | —（后台消费队列） | 按档位自动拉起进程组，日志 `backend/logs/worker-<组>.log` |

`Ctrl+C` 统一退出全部进程。端口覆盖：`API_PORT=8080 WEB_PORT=5173 ./scripts/start.sh`。

### 健康检查

```bash
curl http://127.0.0.1:8000/healthz     # 200 = API 正常
redis-cli llen image.free              # 队列积压数
pgrep -fl 'celery -A'                  # worker 进程
```

## 2. 首次配置（设置页）

打开 http://localhost:3000 → 右上角「设置」：

1. **供应商**：文本 / 图像 / 视频默认统一 Agnes（免费档模型，`catalog` 标 free）；未填 Key 时自动 Mock，全流程仍可跑通（占位图 / 占位视频 / 占位音频）。
2. **配音**：默认小米 MiMo-TTS 官方免费额度；可切 TokenDance / Edge-TTS / 本地引擎。
3. **提示词模板**：8 类全局模板可改；项目内可再定制（项目 > 全局 > 内置 三级优先）。
4. **自动连播**：默认开启（出图完成自动进入视频→配音→合成）。关闭后每阶段需手动点按钮。

> 配置优先级：设置页（数据库）> `.env.local` > `.env` > 内置默认。

## 3. 四步流水线操作

### 第一步 · 剧本工坊

| 小步骤 | 操作 | 说明 |
|---|---|---|
| 上传小说 | 粘贴正文或选 `.txt/.md` → 「导入小说」 | 自动按「第X章」切分章节 |
| 提炼角色 | 点「提炼角色」 | LLM 产出角色卡（外貌/性格/配音建议），逐张可编辑 |
| 分集大纲 | 设定集数 → 「生成大纲」 | 每集标题 + 梗概 + 集尾钩子 |
| 分集剧本 | 逐集点「生成剧本」 | 场景/动作/台词结构化；已生成集自动禁用防覆盖 |

### 第二步 · 资产工厂

| 小步骤 | 操作 | 说明 |
|---|---|---|
| 角色定妆照 | 「智能匹配音色」→「全部生成」→ 逐角色「锁定」 | 每角色正面/侧面/全身 3 图；**锁定（APPROVED）后才会作为分镜参考图** |
| 场景空镜 | 「全部生成」→ 审阅 | 无人物环境图，供分镜背景引用 |
| 道具设计 | 同上 | 关键道具设计稿 |

### 第三步 · 分镜车间

1. 「选择剧集」→ 点目标集。
2. 「AI 分镜」：剧本 → 镜头清单（景别/机位/运镜/时长/台词）。
3. 「批量出图」：每镜独立任务，自动引用已锁定资产作参考图。
4. 审阅：单镜头「重出 / 出图 / 否决 / 删除」；出图失败的镜头点「出图」即可单独重试。

### 第四步 · 视频合成厂

1. 「选择剧集」→「▶ 自动逐集生产」（自动连播开启时其实已自动推进）。
2. 阶段顺序：**视频（图生微动态）→ 配音（TTS）→ 合成（ffmpeg 混音+字幕）**，任一阶段可按单镜头触发。
3. 「成片预览」播放，确认后「导出成片」（1080p MP4 + SRT，落在 `backend/storage/exports/`）。

## 4. 任务中心与调度

入口：任意页右上「任务与费用」（项目内）或顶部「任务中心」（全站 `/tasks`）。

- **档位徽标**：显示「免费串行档」或「付费并行档 ×N」，悬停查看各能力档位明细。
- **状态含义**：
  - `排队中`：等待 worker 消费的队列消息。
  - `处理中` + `⏳ 限流等待重试（第N次），约 M 秒后重试`：供应商限流（503/429），系统自动退避重试（最多 6 次），**不是故障**，等待即可。
  - `失败`：点击错误文案展开完整原因，可点 ↻重试。
- **流水线 暂停/继续**：暂停后 workers 只取不执行（用于止血）。
- **逐集闸门**：前一集镜头未全部完成时，后一集显示「🔒 第 N 集未完成」且入口禁用；这是逐集串行设计（保证素材顺序与限流配额集中供给当前集）。确需越序，API 层 `POST /api/projects/{id}/compose` 传 `"force": true`。
- **失败镜头**：默认阻塞本集推进；可用「跳过该镜头」（SHOT_SKIPPED）放行，或修复后重试。

## 5. 常见问题（FAQ）

**Q1：视频一直「限流等待重试」正常吗？**
正常。免费视频模型通常 1 次/分钟且高峰期返回 503（队列满），系统按 60→120→180→240→300 秒退避自动重试。单集 13 镜约需 15-30 分钟。着急出片可在设置页切换付费视频模型（自动进入并行档）。

**Q2：出图/视频任务卡在「排队中」不动？**
多为 worker 正在执行前序长任务（免费档串行）。到 `backend/logs/worker-free.log` _tail 查看当前执行项；也可以「任务中心 → 暂停 → 继续」让排队消息重排。

**Q3：重启后所有任务变「已暂停」？**
流水线重启后默认暂停（防止夜间自动重跑历史任务烧配额），任务中心点「▶ 继续」恢复。

**Q4：想强制免费/付费档？**
`backend/.env` 设 `SCHED_TIER=free|paid` 后重启 worker（`backend/scripts/start-workers.sh` 单独重启即可）。

**Q5：如何把某一集所有失败任务重来？**
任务中心筛选该项目的失败任务逐个 ↻；或直接对镜头点「出图 / 生成视频」局部重触发。

**Q6：成片在哪里？**
`backend/storage/exports/`（MP4 + SRT）；项目页「成片预览」可直接播放。

## 6. 免费 / 付费档差异速查

| | 免费档 | 付费档 |
|---|---|---|
| worker | 1 个 solo 进程串行 | 按能力 prefork 并行（默认 2/4/3/4/1） |
| 单集出图耗时（13 镜） | ≈ 4-25 分钟（视限流） | ≈ 1-2 分钟 |
| 单集视频耗时 | 受每分钟 1 次限流 ≈ 15-30 分钟 | 并行 3 路 ≈ 3-5 分钟 |
| 判档依据 | 模型 catalog 标 `free`（如 agnes-3.0-flash） | 标 `paid` 的模型；或 `SCHED_TIER=paid` 强制 |

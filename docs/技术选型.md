# AI漫剧创作平台 — 技术选型表

> 版本：v1.1 | 日期：2026-08-11 | 本次同步：对齐实际依赖版本与默认供应商；"规划"项表示适配器占位未实现

## 1. 核心框架

| 领域 | 选型 | 版本 | 理由 |
|---|---|---|---|
| 前端框架 | Next.js | 16.3 | 应用路由，React 19，服务端简化 |
| 语言 | TypeScript | 5.x | 全栈类型安全 |
| 样式 | Tailwind CSS | v4 | 原子化快速构建 |
| 对象关系映射 | Prisma | 7.9（@prisma/client + @prisma/adapter-pg） | 数据模型即文档，迁移工具成熟 |
| 任务队列 | BullMQ | 6.0 | Redis 驱动，事件完备 |
| Redis 客户端 | ioredis | 6.0 | BullMQ 官方依赖 |

## 2. AI 供应商（适配器层，全部国内直连，可插拔）

> 默认值以 `src/lib/providers/settings.ts` 为准：数据库设置 > 环境变量 > 默认值。

### 文本
| 供应商 | 模型 | 用途 | 状态 |
|---|---|---|---|
| 智谱 GLM（默认） | glm-4.7-flash | 剧本创作与结构化任务（当前免费档） | ✅ 已实现 |
| DeepSeek | deepseek-chat | 可切换文本引擎 | ✅ 已实现 |
| 火山方舟 | doubao-seed | 可切换文本引擎 | ✅ 已实现 |
| 模拟 | - | 无密钥自动降级 | ✅ 已实现 |

### 图像
| 供应商 | 模型 | 用途 | 状态 |
|---|---|---|---|
| 智谱 CogView（默认） | cogview-3-flash / glm-image | 定妆/场景/分镜图（纯文生图，单图串行） | ✅ 已实现 |
| 火山方舟 Seedream | doubao-seedream-5-0 | 定妆/分镜图（多参考图 + 组图模式 1K/2K） | ✅ 已实现 |
| 模拟 | - | 本地占位 PNG | ✅ 已实现 |

### 视频
| 供应商 | 模型 | 用途 | 状态 |
|---|---|---|---|

| 可灵 | kling-v3 系列 | 图生视频（异步提交 + 轮询，5/10 秒） | ✅ 已实现 |

### 配音

## 3. 基础设施

| 组件 | 选型 | 备注 |
|---|---|---|
| PostgreSQL | 18.4（Homebrew 本机） | 元数据库 |
| Redis | 8.8（Homebrew 本机） | 队列 |
| 视频处理 | FFmpeg（系统 ffmpeg） | 合成/转场/字幕/质量抽帧 |
| 文件存储 | 本地 `storage/` | 单用户无 S3 |
| 界面 | Tailwind 组件自研 | 无重型界面库 |

# AI漫剧创作平台 — 技术选型表

> 版本：v2.2 | 日期：2026-10-17 | 本次同步：新增调度环境变量（SCHED_TIER / WORKER_CONCURRENCY_* / SCHED_AUTO_ADVANCE / TEXT_TIMEOUT_SEC），档位化物理队列（见架构文档 ADR-6）

## 1. 核心框架

| 领域 | 选型 | 版本 | 理由 |
|---|---|---|---|
| 前端框架 | Vite + React | Vite 7 / React 19 | 极速 HMR，SPA 单页，无需 SSR |
| 路由 | React Router | 7.x | 客户端路由（`/` `/projects/:id` `/settings` `/tasks` + `/m/*`） |
| 语言 | TypeScript | 5.x | 前后端类型安全 |
| 样式 | Tailwind CSS | v4 | 原子化快速构建（`@theme` 色板） |
| 后端框架 | FastAPI | 0.115+ | 异步 Python，自动交互文档 `/docs` |
| 对象关系映射 | SQLAlchemy (async) | 2.0+ | 2.0 风格 Mapped 类型化模型 + asyncpg 驱动 |
| 数据库迁移 | Alembic | 1.16+ | SQLAlchemy 官方迁移工具（异步引擎） |
| 任务队列 | Celery | 5.5+ | Redis broker，5 条命名队列，成熟可靠 |
| 异步 HTTP 客户端 | httpx | 0.28+ | 供应商 API 调用（同步/异步均支持） |

## 5. 环境变量

见 `backend/.env.example`（复制为 `backend/.env`，配置仅后端使用）：数据库地址 / Redis 地址 / 文本 / 图像 / 视频密钥与模型 / TTS 引擎 / Mock 模式 / 存储目录 / CORS。设置页勾选「同时写入 .env.local」时，配置会持久化到 `backend/.env.local`（加载优先级高于 .env，重启后端后对代码层生效）。

配置加载优先级（`backend/app/core/config.py`）：真实环境变量 > `backend/.env.local` > `backend/.env` > 代码默认值；数据库 provider_settings 可覆盖供应商选择。

调度相关（2026-10-16 新增）：`SCHED_TIER`（free/paid 强制档位）、`WORKER_CONCURRENCY_SCRIPT/IMAGE/VIDEO/AUDIO/COMPOSE`（付费档并行度，默认 2/4/3/4/1）、`SCHED_AUTO_ADVANCE`（自动连播，默认 true）、`TEXT_TIMEOUT_SEC`（LLM 超时，默认 600）。

## 5.1 模型目录（`GET /api/models` → `backend/app/providers/catalog.py`）

- 文本 / 图像 / 视频 / 音频（TTS）四组预设模型清单 + 出厂默认值，前端设置页据此渲染下拉框（可选「✍️ 自定义输入」）
- 数据来源：Agnes 官方文档（wiki.agnes-ai.com，2026-10 调研）/ 小米 MiMo TTS（mimo.mi.com）/ TokenDance 网关音频目录（tokendance.space）/ VoxCPM（voxcpm.readthedocs.io）
- 选择保存仍走 `PUT /api/settings` → `provider_settings` 表；目录本身只读

## 5.2 移动端

- User-Agent 检测：前端 `frontend/src/App.tsx` 的 `useEffect`（移动端 UA 且窗口 < 1024px → 重定向 `/m`），替代原 Next.js `proxy.ts`
- 双端路由：`/` `/projects/:id` `/settings` `/tasks`（Web）与 `/m/*`（移动端 Shell）；组件分 `web|mobile|shared` 三目录
- API 客户端两端共用（`frontend/src/api/client.ts`）

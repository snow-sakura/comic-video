# AI漫剧创作平台 — 产品需求文档（PRD）

> 版本：v2.1 | 日期：2026-10-17 | 状态：已确认（与当前实现同步） | 本次同步：生成调度与并发优化（免费/付费档位、逐集串行、自动连播、限流自适应），单集 E2E 全流程验证通过（2026-10-17）

## 1. 产品定位

**单用户本地运行的 AI 漫剧创作工作台**：输入小说 → 自动产出可发布的漫剧成片。

解决 AI 漫剧三大行业痛点：
1. **角色崩坏**：跨镜头/跨集角色形象漂移 → 通过多参考图定妆 + 资产库锁定解决
2. **流程割裂**：剧本/分镜/视频/配音需在多个软件间切换 → 四步流水线一体化
3. **产能瓶颈**：批量出片效率低 → 异步任务队列 + 逐镜独立任务可并行

## 2. 用户故事

| 角色 | 故事 |
|---|---|
| 个人创作者 | "我上传一本小说，AI 帮我拆出剧本和角色，生成定妆照，拆好分镜，最后自动出成片，我只在关键节点确认和微调" |
| 短视频团队 | "我要批量产出多集漫剧，每集角色必须长得一样，成本可控，能知道每集花了多少钱" |

## 3. 功能需求（四步流水线）

### 3.1 第一步：剧本工坊
| 功能 | 说明 | 验收标准 |
|---|---|---|
| 小说输入 | 粘贴文本 / 上传 .txt/.md 文件 | 支持 10 万字以上长文本，自动章节切分与清洗 |
| 核心梗概生成 | 一句话明确故事核心：主角身份 + 发生事件 + 核心冲突 | 不超过 50 字，可编辑，可重新生成 |
| 角色设定生成 | 三个维度颗粒度刻画：外貌（发型/服饰/面部标志物）、性格（习惯性小动作/情绪反应）、剧作功能（主角/配角/反派/工具人） | 禁用"25岁白领"式模糊描述；JSON 结构化输出；逐项可编辑 |
| 剧本结构化 | 分场分幕；开头 3 行必须含冲突/悬念；心理描写 → 动作+台词；连续剧模式集尾加悬念钩子 | 输出符合剧本结构规范；支持分集（默认 1 集=3-5 分钟） |
| 人工审校 | 每个产出可编辑、可重新生成、可回滚版本 | 版本历史保留 |

### 3.2 第二步：资产工厂
| 功能 | 说明 | 验收标准 |
|---|---|---|
| 资产清单提取 | 从剧本自动提取角色/场景/道具清单 | 与剧本角色一一对应 |
| 角色定妆照 | 每个角色生成多角度参考图：正面/四分之三侧/全身/表情 | 默认逐张生成；Seedream 组图模式一次生成 4-6 张 + 多参考图保证一致性 |
| 场景标准图 | 每个场景生成环境空镜（无人物） | 每场景至少 1 张标准图 |
| 风格锁定 | 全局风格参考图 + 风格描述，贯穿所有生成 | 设置页可上传风格参考图 |
| 资产库管理 | 资产入库/编辑/删除/精选/跨项目复用 | 资产卡界面；精选图作为后续参考图 |

### 3.3 第三步：分镜车间
| 功能 | 说明 | 验收标准 |
|---|---|---|
| AI 拆分镜 | 剧本 → 分镜清单：镜头角度/运镜方式/画面构图/台词匹配/时长 | 每场 3-8 镜；结构校验 |
| 提示词 7 维生成 | 主体/环境/构图/色彩/情绪氛围/风格/灯光 | 自动注入角色定妆照 + 场景空镜 + 风格参考图 |
| 逐镜图像生成 | 一镜一图，逐镜独立任务，禁止九宫格批量 | 每镜独立任务可重试/重生成 |
| 分镜墙 | 时间轴预览全部镜头缩略图 | 任务进行中逐格点亮 |

### 3.4 第四步：视频合成厂
| 功能 | 说明 | 验收标准 |
|---|---|---|
| 微动态视频 | 每镜图生视频 5-15 秒短镜头（发丝微动/光影浮动/缓慢平移） | 默认 5 秒/10 秒；默认 Agnes（可切换智谱 CogVideoX/可灵，角色参考以提示词锁定为主，二次图生视频参考规划中） |
| 质量校验 | 视频生成后自动抽帧检查形变，失败自动重试 | 重试上限 2 次 |
| AI 配音 | 角色 → 音色映射，长文本分段合成，情绪标签 | 默认 Mock，可切换 Edge-TTS（免费）/ 小米 MiMo-TTS / CosyVoice |
| 音效/背景音乐 | 环境音效 AI 生成 + 背景音乐素材库按情绪匹配 | 每镜音效标签自动匹配 |
| 合成导出 | 画面+配音+字幕+转场 FFmpeg 合成 | 1080p H.264 + SRT 字幕；转场库（淡入/淡出/叠化） |
| 费用追踪 | 项目/集/镜头三级费用统计，生成前预估 | 按供应商分策略计费 |

### 3.5 横切能力：智能调度与并发（2026-10-16 新增）
| 功能 | 说明 | 验收标准 |
|---|---|---|
| 免费/付费档位 | 模型按 catalog 标签自动判档（`SCHED_TIER` 可强制）；免费档单任务串行（solo），付费档多进程并行（prefork，进程组隔离） | 免费配置进程组全 1；paid 档 script=2/image=4/video=3/audio=4/compose=1，环境变量可覆盖 |
| 限流自适应 | 供应商限流（503/429/队列满）与瞬态网络错误时任务级自动延迟重入队（最多 6 次，退避 60-300s），期间 UI 显示「⏳ 限流等待重试（第N次）」而非失败 | 任务最终 DONE 或重试耗尽 FAILED（error 含原始错误）；等待期间闸门保持 |
| 逐集串行 | 生成视频必须上一集全部镜头完成才能进入下一集；被阻塞集显示「🔒 第 N 集未完成」并禁用入口；409 返回 blockedBy/missing/failed | 第 2 集点生成 → 409；第 1 集合成完成后第 2 集自动放行 |
| 自动连播 | 镜头出图完成 → 自动入队视频 → 配音 → 合成，全程无人值守推进到成片；可在设置/任务中心关闭 | 关闭后仅手动推进；开启时单集所有镜头自动流经四阶段 |
| 失败镜头处理 | 默认阻塞该集；提供「跳过该镜头」（SHOT_SKIPPED）放行继续 | 跳过后闸门计数不含该镜头 |
| 调度可视化 | 任务中心显示档位徽标（免费串行档/付费并行档×N）、队列深度、限流等待态；`GET /api/scheduler/status` | 徽标与实际配置一致；autoAdvance 可往返切换 |

## 4. 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 付费档可并行（档位化队列：script=2/image=4/video=3/audio=4）；免费档自动降为串行避免限流空耗；页面加载小于 2 秒 |
| 可靠性 | 所有 AI 任务异步化，失败可重试；限流/瞬态网络错误自动延迟重入队（任务级，最多 6 次）；任务状态持久化；重启后默认暂停流水线防历史任务自动重跑 |
| 可用性 | 单用户本地工具，无需注册登录；`./scripts/start.sh` 一条命令启动（自动迁移数据库并同时启动 API、任务队列 Worker 与前端，Ctrl+C 统一退出；也支持 `start-backend.sh` / `start-frontend.sh` 分别启动） |
| 成本 | 单集（3 分钟）制作成本预算 ¥40-70（图像 ¥2-5 + 视频 ¥30-60 + 配音 ¥1-3） |
| 扩展性 | 供应商适配器可插拔，任何环节可替换/降级 |

## 5. 边界与取舍

- 不做多用户/权限系统（定位单用户本地工具，后续可扩展）
- 不做云端部署（本地运行）
- 视频精度优先于速度（逐镜生成，不做九宫格批量）
- 配音默认本地 Mock（可切换 Edge-TTS / 小米 MiMo-TTS / 阿里百炼 CosyVoice），适配器支持扩展其他引擎（模型目录见 `GET /api/models`）
- 全部国内 API，无需翻墙

## 6. 执行流程验收

四步流水线全部端到端跑通（ep1/ep2 均达 `DONE/COMPOSED`，成片输出至 `backend/storage/exports/`），验收记录如下（原全流程截图已随 `docs/media/` 一并清理，如需复现请按 README 操作）：

| 阶段 | 验收要点 | 结果 |
|---|---|---|
| 01 剧本工坊 | 上传小说 → 角色提炼（6 角色卡 + gender）→ 分集大纲（6 集）→ 分集剧本（场景/台词/钩子） | ✓ |
| 02 资产工厂 | 角色定妆照（6 卡 + 音色匹配）→ 场景空镜（草稿/锁定）→ 道具设计 | ✓ |
| 03 分镜车间 | 选剧集 → 分镜出图（景别/机位/状态/台词），逐镜独立任务 | ✓ |
| 04 视频合成厂 | 选剧集 → 成片预览/播放器 → 镜头配音 + BGM + 字幕 → FFmpeg 合成导出 | ✓ |
| 辅助 | 供应商设置 / 提示词模板（8 全局）/ 任务中心（暂停/重试） | ✓ |

示例项目《天工残卷：铜皮秘符》：6 集剧本、75 镜头、多集成片（`backend/storage/exports/`），验证了角色一致性锁定、7 维提示词、微动态视频、配音与 FFmpeg 合成全链路。

**调度优化后单集 E2E 复验（2026-10-17，项目「单集E2E验证」）**：新建项目 → 导入小说（2 章）→ 提炼角色（2 卡+音色）→ 1 集大纲 → 第 1 集剧本 → 6 张定妆照 + 锁定 2/2 → AI 分镜 13 镜头 → 批量出图 13/13（含限流等待重试、失败镜头单点重出兜底）→ 出图完成自动连播入队 13 个视频任务。全程浏览器自动化验证 0 console 报错；逐集闸门在 2 集项目实测第 2 集正确锁定。逐项验收结论见 `docs/specs/2026-10-16-生成调度与并发优化-spec.md` 验收表（验证证据截图为一次性产物，已清理不入库）。

> 验收方法：`./scripts/start.sh` 启动后按 README「四步流水线」逐步操作；无密钥时 Mock 模式全流程可跑通。

# AI漫剧创作平台 — 架构文档

> 版本：v1.1 | 日期：2026-08-11 | 本次同步：与代码实现对齐（默认供应商 / 轮询进度 / 队列并发 / 模型数量）

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                   Next.js 16 全栈应用（单用户本地）              │
│  ┌─────────────┐  ┌───────────┐  ┌──────────┐  ┌───────────┐ │
│  │① 剧本工坊   │→ │② 资产工厂  │→ │③ 分镜车间 │→ │④ 视频合成厂│ │
│  │ 3个LLM智能体│  │   出图引擎 │  │ 分镜智能体│  │  视频引擎  │ │
│  │ 梗概/角色/  │  │ 定妆/空镜/ │  │ 提示词7维 │  │ 配音引擎   │ │
│  │ 剧本结构化  │  │ 道具+精选  │  │ 逐镜生成  │  │ FFmpeg     │ │
│  └─────────────┘  └───────────┘  └──────────┘  └───────────┘ │
├─────────────────────────────────────────────────────────────┤
│       任务编排层：BullMQ 队列（5队列）+ 状态机 + 前端轮询进度   │
├─────────────────────────────────────────────────────────────┤
│  数据层：PostgreSQL（Prisma）+ Redis（BullMQ）+ storage/     │
├─────────────────────────────────────────────────────────────┤
│  供应商适配层：文本 / 图像 / 视频 / 配音 / 音乐 / 音效（可插拔） │
│  默认：智谱 GLM · 智谱 CogView · 智谱 CogVideoX · Mock 配音   │
└─────────────────────────────────────────────────────────────┘
```

说明：
- 队列状态变更后，工作台通过**前端轮询**获取进度（各工作台每 2 秒、任务中心每 4 秒），未采用服务器推送。
- 配音默认走本地 Mock（无声轨占位），配置 `TTS_API_KEY` 后可切换 Edge-TTS（免费）或 CosyVoice。

## 2. 架构决策记录（ADR）

### ADR-1：Next.js 16 全栈
- **决策**：React 19 + 应用路由 + TypeScript + Tailwind CSS v4
- **理由**：AI 软件开发工具包（SDK）原生支持 DeepSeek/OpenAI 兼容端点；服务端简化表单驱动长任务；单进程部署简化运维；分镜墙受益于 React 并发渲染
- **备选**：Next.js + FastAPI 分离（否决：增加运维复杂度，AI 调用皆为 HTTP 应用程序接口（API）无需 Python 生态）

### ADR-2：文本模型策略（默认智谱 GLM，可插拔）
| 用途 | 默认模型 | 可切换 |
|---|---|---|
| 剧本创作与结构化任务 | 智谱 GLM（glm-4.7-flash，免费档） | DeepSeek（deepseek-chat）、豆包（doubao-seed） |
- 统一 `大语言模型供应商` 接口（`src/lib/providers/types.ts`），按设置页/环境变量路由
- 适配要点（`src/lib/providers/llm/index.ts`）：
  - AI SDK v7 默认禁止 messages 中的 system 角色，系统提示统一拆出为顶层 `system` 参数（兼容 OpenAI Chat Completions 协议，智谱/豆包/DeepSeek 均支持）
  - glm-4.7 系列默认开启思考模式，reasoning_tokens 会吃光小预算导致输出为空；GLM 请求经自定义 fetch 注入 `thinking: {type:"disabled"}` 关闭
  - 免费档高峰期间歇限流（错误码 1305），GLM 调用配置 maxRetries=4；仍失败时智能体降级为启发式提取（保证流程不中断）
- **已知问题**：glm-4.7-flash 免费档在高峰时段限流明显，若任务频繁失败可在设置页切换 DeepSeek 或升级付费档

### ADR-3：角色一致性 = 多参考图书写 + 提示词锁定
- **定妆**：文生图（可参考图）→ 精选图入库（角色 refImageIds / 场景 / 道具）
- **分镜**：每镜生成携带 [角色定妆照 + 场景空镜 + 风格] 关键词与参考图（Seedream 支持真实参考图，CogView 为纯文生图）
- **失败兜底现状**：视频阶段"再携带主体参考二次锁定"尚未完整实现（当前以提示词外观锁定为主），列为待办增强

### ADR-4：视频引擎 = 智谱 CogVideoX 默认，可灵已实现，Vidu 规划
- 智谱 CogVideoX（默认，模型 cogvideox-flash，异步任务 + 轮询）
- 可灵：已实现（异步提交 + 轮询，支持 5/10 秒时长）
- Vidu：规划未实现（适配器返回 Mock 占位）
- **微动态策略**：每镜独立生成 5 秒/10 秒短片段，规避长视频形变

### ADR-5：配音 = Mock 默认（可插拔）
- Mock：无密钥时静音占位，保证全流程可跑通
- Edge-TTS：微软免费合成（无需密钥），实时可用
- CosyVoice（阿里百炼）：可选，中文自然度优先，支持多音色
- MiniMax / 小米等其余引擎：规划未实现

### ADR-6：任务编排 = BullMQ（Redis）
- 5 队列：`script` / `image` / `video` / `audio` / `compose`
- 状态机：`已排队 → 处理中 → 完成 | 失败`（失败自动重试最多 2 次，可手动重试）
- 进度获取：从 `处理中` 状态持久化 + **前端轮询**（`/api/projects/[id]` 等查询接口）

### ADR-7：数据存储
- PostgreSQL（Prisma 对象关系映射（ORM））：全部业务元数据
- Redis：队列
- 本地文件系统 `storage/`：图片/视频/音频/字幕（单用户无需 S3）

### ADR-8：提示词工程策略
- **情绪驱动**：大纲阶段要求每集 1 个高情绪点；分镜阶段 `emotionPalette()` 按台词情绪映射色彩基调（浪漫樱粉/愤怒暖橙/夜晚冷蓝…）注入 7 维提示词
- **出图可绘制性**：大纲 `time` 字段要求携带可出图的光线词（黄昏/逆光/霓虹…）；场景图按前景/中景/背景三层纵深；角色图含光影/材质约束并禁止 logo/水印
- **TTS 友好对白**：单句 ≤ 30 字、口语化；镜头 `action` 结构化为「光线 + 动作 + 环境 + 景别」；对话镜头带口型提示（`dialogMotionHint`）
- **启发式回退**：LLM 不可用时全链路降级为规则组装，保证流程可跑通（`agents/json.ts` 容错解析兜底）

### ADR-9：浅色日式治愈主题
- 不逐组件改样式，改为 Tailwind v4 `@theme inline` 整体色板映射：`zinc-950 → #f6f2ea`（米白纸感底）、`zinc-100 → #3e372e`（深棕墨）、violet → 抹茶绿、red → 砖红、emerald → 苔绿、amber → 暖杏
- body 背景 = 暖渐变 + 纸纹点阵；滚动条/选区/焦点环同步柔和化；全站零组件改动即换肤
- 决策理由：组件多（4 个工作台 + 通用组件），色板层替换成本最低且不会出现漏改色块

### ADR-10：设置面板 = 五分组 TABS
- `SETTING_GROUPS` 声明分组（通用/文本/图像/视频/音频），`FIELD` 常量平铺引用字段，避免重复定义
- 分组 TABS + 脏计数角标 + 「保存 N 项变更」按钮；切换分组不丢失未保存修改
- `SETTING_FIELDS` 保留为平铺兼容导出（当前无外部引用，后续工作台读设置可复用）

### ADR-11：在线体验 = 纯静态 GitHub Pages
- `demo/index.html`：零依赖单文件（内联 CSS/JS），内置样例数据（角色/大纲/剧本/分镜/音频），四步 TABS + 模拟进度/视频播放/导出，完整还原主站交互
- 部署：`.github/workflows/pages.yml`，push 到 `main` 且 `demo/**` 变更时自动构建发布
- 决策理由：体验页不允许携带密钥/数据库，静态样例最安全；与主仓库同仓避免多仓库维护成本

## 3. 数据模型

核心实体：`项目 → (剧本, 角色[], 场景[], 集[], 资产[])`，`集 → 镜头[]`，全部 AI 任务统一 `生成任务` 追踪（含费用）。

详见 `prisma/schema.prisma`（9 个模型 + 6 个枚举），已应用 6 次迁移。

## 4. 队列设计

| 队列 | 任务类型 | 默认并发 | 典型耗时 | 依赖 |
|---|---|---|---|---|
| script | 文本模型生成（梗概/角色/剧本/分镜） | 1 | 10-60 秒 | 无 |
| image | 定妆/场景/分镜图 | 2 | 30-90 秒 | 文本产出 |
| video | 图生视频（智谱/可灵） | 2 | 30 秒-3 分钟 | 分镜图 |
| audio | 配音/背景音乐/音效 | 2 | 10-60 秒 | 剧本台词 |
| compose | FFmpeg 合成 | 1 | 1-5 分钟 | 视频+音频+字幕 |

并发可通过环境变量 `WORKER_CONCURRENCY_SCRIPT / _IMAGE / _VIDEO / _AUDIO / _COMPOSE` 覆盖。

## 5. 供应商适配器契约

统一接口 `供应商配置 / 任务句柄 / 大语言模型供应商 / 图像供应商 / 视频供应商 / 配音供应商 / 音乐供应商 / 音效供应商`，定义于 `src/lib/providers/types.ts`。`registry.ts` 按配置路由（数据库设置 > 环境变量 > 默认值），全部支持模拟模式（无密钥时用本地占位图/静音音频，保证全流程可跑通）。

## 6. 安全与合规

- API 密钥仅存本地（`src/lib/env.ts` 按 `.env.local` > `.env` 顺序加载），设置页可配置
- 商业版权：各平台 API 输出版权按平台条款；Edge-TTS 仅作免费兜底标注风险
- 无用户数据上云（文件全本地）

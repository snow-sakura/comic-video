# AI漫剧创作平台 — 架构文档

> 版本：v2.1 | 日期：2026-10-17 | 本次同步：生成调度与并发优化（免费/付费档位物理队列拆分 Free/Paid + worker 进程组 + 限流自动重入队 + 逐集串行闸门），详见 `docs/specs/2026-10-16-生成调度与并发优化-spec.md`

## 1. 总体架构

```
┌──────────────────────────┐        ┌─────────────────────────────────────────┐
│  frontend/（Vite + React）│  HTTP  │           backend/（FastAPI + Celery）   │
│  ┌────────────────────┐  │ /api、 │  ┌─────────────┐  ┌───────────┐         │
│  │ 四步工作台 SPA      │  │ /file  │  │① 剧本工坊   │→│② 资产工厂  │         │
│  │ script/asset/       │──┼───────▶  │ 3个LLM智能体│  │  出图引擎  │         │
│  │ storyboard/compose  │  │ Vite   │  │ 梗概/角色/  │  │ 定妆/空镜/ │         │
│  │ + 设置/任务中心      │  │ 代理   │  │ 剧本结构化  │  │ 道具+精选  │         │
│  └────────────────────┘  │ :8000  │  └─────────────┘  └───────────┘         │
│  轮询进度（2s/4s）        │        │  ┌──────────┐  ┌───────────┐            │
└──────────────────────────┘        │→│③ 分镜车间 │→│④ 视频合成厂│            │
                                    │  │ 分镜智能体│  │ 视频引擎   │            │
                                    │  │ 提示词7维 │  │ 配音引擎   │            │
                                    │  │ 逐镜生成  │  │ FFmpeg    │            │
                                    │  └──────────┘  └───────────┘            │
                                    ├─────────────────────────────────────────┤
                                    │ 任务编排层：Celery 档位化队列（Redis）  │
                                    │ script/image/video/audio × free/paid    │
                                    │ + compose · free=solo · paid=prefork    │
                                    ├─────────────────────────────────────────┤
                                    │  数据层：PostgreSQL（SQLAlchemy async）   │
                                    │  + Redis + backend/storage/             │
                                    ├─────────────────────────────────────────┤
                                    │  供应商适配层：文本/图像/视频/配音/音乐/音效 │
                                    │  默认 Agnes AI · 无 Key 自动 Mock         │
                                    └─────────────────────────────────────────┘
```

说明：
- 前端为纯 SPA，开发环境 Vite 将 `/api`、`/file` 代理到 `http://localhost:8000`；生产通过 `CORS_ORIGINS` 放行。
- 队列状态变更后，工作台通过**前端轮询**获取进度（各工作台每 2 秒、任务中心每 4 秒），未采用服务器推送。
- 配音默认走本地 Mock（ffmpeg 生成占位 MP3），配置 `TTS_ENGINE` 后可切换 Edge-TTS（免费）或 CosyVoice。
- 启动方式：`./scripts/start.sh` 一键拉起 API + Worker + 前端三进程；或分别用 `start-backend.sh` / `start-frontend.sh`；也可在 `backend/` 下直接 `python run.py`（FastAPI 独立入口，支持 `--host/--port/--reload`）或 `python -m app.main`。

## 2. 架构决策记录（ADR）

### ADR-1：前后端分离（Vite + React SPA ｜ FastAPI + Celery）
- **决策**：`frontend/`（Vite 7 + React 19 + React Router 7 + Tailwind v4）与 `backend/`（FastAPI + Celery + SQLAlchemy async + Alembic）完全分离，各自独立目录、独立依赖、独立启动
- **理由**：Python 生态（ffmpeg 控制、异步 HTTP、PIL、TTS）更适合 AI 流水线后端；Vite HMR 开发体验远优于 Next.js；前后端可独立部署与扩展
- **演进**：v1 为 Next.js 16 单体（BullMQ + Prisma），P4 重构为本架构；旧单体代码已删除（git 历史可查）
- **备选**：保持 Next.js 单体（否决：AI 调用与视频处理需要 Python；单体队列进程与 Web 进程耦合）

### ADR-2：文本模型策略（默认 Agnes AI，可插拔）
| 用途 | 默认模型 | 可切换 |
|---|---|---|
| 剧本创作与结构化任务 | Agnes agnes-3.0-flash（免费档） | Agnes 全系（2.5-flash / 2.5-pro / 3.0-flash-max…）、通用 OpenAI 兼容（OpenCode Zen 免费档、小米 MiMo v2.6 等） |
- 统一 `大语言模型供应商` 接口（`backend/app/providers/`），按设置页/环境变量路由；模型目录集中在 `backend/app/providers/catalog.py`，设置页经 `GET /api/models` 渲染下拉框
- 适配要点：
  - OpenAI Chat Completions 协议兼容（Agnes/OpenAI 兼容端点），系统提示作为顶层 `system` 参数
  - 免费档高峰限流时配置指数退避重试（429/5xx，上限 120s）；仍失败时智能体降级为启发式提取（保证流程不中断）
- **已知问题**：免费档高峰限流明显，任务频繁失败可在设置页切换模型或升级付费档

### ADR-3：角色一致性 = 多参考图书写 + 提示词锁定
- **定妆**：文生图（可参考图）→ 精选图入库（角色 refImageIds / 场景 / 道具）
- **分镜**：每镜生成携带 [角色定妆照 + 场景空镜 + 风格] 关键词与参考图（Agnes Image 系列支持多图参考输入）
- **失败兜底现状**：视频阶段"再携带主体参考二次锁定"尚未完整实现（当前以提示词外观锁定为主），列为待办增强

### ADR-4：视频引擎 = Agnes 默认（可插拔，Mock 兜底）
- Agnes agnes-video-2.5-flash（默认，限时免费；限流 1 次/分钟，队列满 503 时自动降级 Mock）
- 可选 agnes-video-2.5（正价档，多模态参考生成）
- 其它视频供应商（智谱/可灵/Vidu 等）当前未接实现，目录预留可扩展
- **微动态策略**：每镜独立生成 5 秒/10 秒短片段，规避长视频形变

### ADR-5：配音 = Mock 默认（可插拔，引擎目录可扩展）
- Mock：无密钥时 ffmpeg 生成可解析占位 MP3（按文本估算时长），字幕存独立 JSON，保证全流程可跑通
- Edge-TTS：微软免费合成（无需密钥），10 款内置中文神经音色
- 小米 MiMo-TTS：OpenAI 兼容 `/v1/audio/speech`（mimo-v2.5-tts / voiceclone / voicedesign），全免费额度；可直接配置或经 TokenDance 网关（`tts.baseUrl` 改指向 `https://tokendance.space/gateway/v1`）调用；无 Key 时 Mock 兜底
- 本地 confucius4：6 款内置音色，供角色音色匹配
- VoxCPM 2（OpenBMB 本地开源）：目录已收录（`GET /api/models`），零费用本地推理，适配器规划中
- 按量付费引擎（MiniMax / 豆包 / CosyVoice）已从目录移除，保留免费选项

### ADR-6：任务编排 = Celery 5（Redis broker · 档位化物理队列）
- **物理队列按「能力 × 档位」拆分**：`script.{free,paid}` / `image.{free,paid}` / `video.{free,paid}` / `audio.{free,paid}` + 共享 `compose`，共 9 条（`backend/app/core/celery_app.py` 的 `QUEUE_NAMES`）。旧单段队列名（`script`/`image`…）已废弃。
- **档位判定**（`backend/app/scheduler/tier.py`）：模型 catalog `tags` 含 `free` → 免费档；含 `paid` → 付费档；`SCHED_TIER=free|paid` 强制覆盖。入队时 `resolve_queue` 按模型路由并把 `_tier` 记入 payload，限流重入队沿用原通道，避免付费任务误回落免费串行队列。
- **worker 进程组**（`app/batch_plan.py --shell` 输出 `name|queues|concurrency|pool`，启动脚本据此拉起）：
  - 免费档：单 `solo` 进程串行消费 `script.free,image.free,video.free,audio.free,compose`（契合免费模型限流，避免并发打爆）
  - 付费档：按能力拆 `prefork` 组并行，默认并行度 `script=2 / image=4 / video=3 / audio=4 / compose=1`，`WORKER_CONCURRENCY_*` 可覆盖
- 进程隔离（非线程池）：Celery `run_async` 会改写模块级 `SessionLocal`，线程不安全，故用独立 worker 进程组实现并行。
- **限流/瞬态自动重入队**：视频/图像遇 Agnes 503/429/队列满 或瞬态网络错误时，任务级延迟重入队（`delay=min(60*(n+1),300)`，最多 6 次），DB 写「限流等待重试（第N次）」且保持 PROCESSING，闸门继续关闭。
- 状态机：`已排队 → 处理中 → 完成 | 失败`；进度经 `GenTask` 表 + **前端轮询**获取。
- 逐集串行闸门见 ADR-16。

### ADR-7：数据存储
- PostgreSQL + SQLAlchemy 2.0 async（`backend/app/models/models.py`，11 表）：全部业务元数据
- Alembic 异步迁移（`backend/alembic/`，基线 `0001_baseline` 已 stamp）
- Redis：Celery broker / result backend
- 本地文件系统 `backend/storage/`：图片/视频/音频/字幕（单用户无需 S3）

### ADR-8：提示词工程策略
- **情绪驱动**：大纲阶段要求每集 1 个高情绪点；分镜阶段 `emotion_palette()` 按台词情绪映射色彩基调（浪漫樱粉/愤怒暖橙/夜晚冷蓝…）注入 7 维提示词
- **出图可绘制性**：大纲 `time` 字段要求携带可出图的光线词（黄昏/逆光/霓虹…）；场景图按前景/中景/背景三层纵深；角色图含光影/材质约束并禁止 logo/水印
- **TTS 友好对白**：单句 ≤ 30 字、口语化；镜头 `action` 结构化为「光线 + 动作 + 环境 + 景别」；对话镜头带口型提示（`dialog_motion_hint`）
- **启发式回退**：LLM 不可用时全链路降级为规则组装，保证流程可跑通（`backend/app/json_utils.py` 容错解析兜底）

### ADR-9：浅色日式治愈主题
- 不逐组件改样式，改为 Tailwind v4 `@theme inline` 整体色板映射：`zinc-950 → #f6f2ea`（米白纸感底）、`zinc-100 → #3e372e`（深棕墨）、violet → 抹茶绿、red → 砖红、emerald → 苔绿、amber → 暖杏
- body 背景 = 暖渐变 + 纸纹点阵；滚动条/选区/焦点环同步柔和化；全站零组件改动即换肤
- 决策理由：组件多（4 个工作台 + 通用组件），色板层替换成本最低且不会出现漏改色块

### ADR-10：设置面板 = 五分组 TABS + 模型目录联动
- `SETTING_GROUPS` 声明分组（通用/文本/图像/视频/音频），`FIELD` 常量平铺引用字段，避免重复定义
- 供应商 / 模型 / TTS 引擎选项由 `GET /api/models`（`backend/app/providers/catalog.py`）动态注入：默认 Agnes 全系免费模型 + 小米 MiMo-TTS + TokenDance 音频目录（MiniMax/豆包/VoxCPM）；每个模型字段支持「✍️ 自定义输入」自由填写
- 分组 TABS + 脏计数角标 + 「保存 N 项变更」按钮；切换分组不丢失未保存修改
- 配置优先级：数据库 provider_settings > `backend/.env.local` > 环境变量 `backend/.env` > 代码默认值（`backend/app/core/config.py`）；设置页可勾选同步写入 `.env.local` 持久化

### ADR-11：提示词工程可视化 = PromptTemplate 表（三级解析）
- `PromptTemplate` 表（global / project 双 scope）承载全部提示词模板：角色提炼与世界观 / 分集大纲 / 单集分镜剧本 / 分镜切分 / 角色定妆照 / 场景空镜 / 道具设计图 / 视频微动态，共 8 类
- 解析优先级：**项目定制 > 全局模板（设置页管理，覆盖所有小说）> 代码内置默认**
- 无模板记录时自动回落到代码内置默认，保证不会因缺表数据而中断

### ADR-12：流水线全局控制 = PipelineControl 单行表
- 单行表（id 恒为 1）`paused` 布尔控制 Worker 是否消费新任务；重启后默认暂停，防止自动重跑历史任务
- 任务中心「⏸ 暂停 / ▶ 继续」一键切换；Worker 每次取任务前检查，暂停期间新任务仅排队不消费

### ADR-13：音色性别纠正 = Character.gender
- 角色卡 `gender` 字段，TTS 音色分配/校验时按性别纠正（如「confucius-deep」→ 女声纠正为「confucius-feminine」），拒绝非法音色 ID，避免配音与角色性别不匹配

### ADR-14：移动端适配 = 前端 UA 检测 + 双路由
- `frontend/src/App.tsx` 的 `useEffect` 按 User-Agent + 视口宽度重定向移动设备到 `/m/*`（替代原 Next.js `proxy.ts`）
- 代码双路独立：Web 页面 `frontend/src/pages/` 与移动端 `frontend/src/pages/mobile/`（组件分 `components/web|mobile|shared`），API 客户端 `frontend/src/api/client.ts` 两端共用

### ADR-15：端到端可靠化（重构期修复）
- Celery handler 内同步 I/O 用 `subprocess.run`（禁止嵌套 `asyncio.run`）
- 字幕路径存独立 JSON 文件（`storage/subs/*.json`），规避 `subtitle_path VARCHAR(500)` 溢出导致的事务中断
- 会话异常先 `db.rollback()` 再标失败状态，防止事务 abort 后写库连锁失败
- ffmpeg concat 音频输入补 `-f concat -safe 0`；相对路径统一转绝对路径

### ADR-16：逐集串行闸门 + 自动连播（2026-10-16）
- **闸门**（`backend/app/production.py`）：`first_blocking_episode()` 检查「前一集是否全部镜头视频完成」，未完成时 `POST /api/projects/{id}/compose` 返回 **409** `{error, blockedBy, missing, failed, reason}`；`force:true` 直通（任务中心高级操作）。
- **集状态机**：`Episode.status ∈ producing / composing / composed / failed`；镜头任务完成经 settle 钩子推进 `settle_episode_step`。
- **失败镜头**（D5）：默认阻塞该集推进；`POST /produce {skipFailed:true}` 或镜头「跳过该镜头」按钮置 `SHOT_SKIPPED` 放行。
- **自动连播**（D3，默认开）：镜头/集任务 DONE 后 settle 钩子自动入队下一阶段（出图→视频→配音→合成→下一集），优先级 DB `sched.autoAdvance`（设置页/`POST /api/scheduler/status` 可切换）> env `SCHED_AUTO_ADVANCE` > 默认 true。
- **前端**：被阻塞集显示「🔒 第 N 集未完成」并禁用生成按钮；409 detail 对象解析为可读提示。
- 幂等保护：续排器多 worker 场景以 `Episode.status` 原子更新保证单次入队。

## 3. 数据模型

核心实体：`项目 → (剧本, 角色[], 场景[], 集[], 资产[])`，`集 → 镜头[]`，全部 AI 任务统一 `生成任务` 追踪（含费用）。

详见 `backend/app/models/models.py`（11 表：projects / scripts / characters / scenes / assets / episodes / shots / pipeline_controls / provider_settings / prompt_templates / gen_tasks；状态用字符串常量对齐原枚举）。

> 库中另存旧 Next.js 时代的 PascalCase 表（`Project` / `Shot` 等，含历史数据）：**已确认保留**，当前代码不读写，与新表共存。

## 4. 队列设计（档位化物理队列 · 2026-10-16）

物理队列 = `能力.{free|paid}` + 共享 `compose`，共 9 条。入队时按所用模型档位路由（`resolve_queue`），worker 进程组按档位消费。

| 能力 | 任务类型 | 免费档并发 | 付费档并发* | 典型耗时 | 依赖 |
|---|---|---|---|---|---|
| script | 文本模型生成（梗概/角色/剧本/分镜） | 1（solo） | 2 | 10-60 秒（LLM 超时 600s） | 无 |
| image | 定妆/场景/分镜图 | 1（solo） | 4 | 15-90 秒 | 文本产出 |
| video | 图生视频（Agnes/智谱/可灵） | 1（solo） | 3 | 30 秒-3 分钟 | 分镜图 |
| audio | 配音/背景音乐/音效 + 字幕 | 1（solo） | 4 | 10-60 秒 | 剧本台词 |
| compose | FFmpeg 合成 | 1 | 1 | 1-5 分钟 | 视频+音频+字幕 |

\* 付费档默认并行度，`WORKER_CONCURRENCY_*` 环境变量可覆盖；免费档全 1 是因免费模型普遍限流（如 Agnes 视频 1 次/分钟），并行只会空耗重试。

Worker 进程组启动：`backend/scripts/start-workers.sh`（消费 `app.batch_plan --shell` 输出的 `name|queues|concurrency|pool` 计划）；免费档单 solo 进程 + 付费档按能力 prefork 组。手动选择队列示例：`celery -A app.core.celery_app worker -Q script.free,image.free,video.free,audio.free,compose --pool=solo`。

任务中心（`/api/tasks` + `/api/tasks/{id}/retry|resume` + 前端 4 秒轮询）统一查看全部项目任务（状态 / 耗时 / 费用 / 失败原因），支持失败任务一键重试；流水线控制（`/api/pipeline`）一键暂停 / 继续。

## 5. 供应商适配器契约

统一接口定义于 `backend/app/providers/`（types + registry + 各供应商实现）。`registry` 按配置路由（数据库设置 > 环境变量 > 默认值），全部支持模拟模式（无密钥时用本地占位图/ffmpeg 占位视频/占位音频，保证全流程可跑通）。

## 6. 安全与合规

- API 密钥仅存本地（`backend/.env`，被 git 忽略；`/api/env` 返回时敏感值打码），设置页可配置
- 商业版权：各平台 API 输出版权按平台条款；Edge-TTS 仅作免费兜底标注风险
- 无用户数据上云（文件全本地 `backend/storage/`）

## 执行原则

1. **每步完成即验证**：lint + 类型检查 + 运行冒烟测试
2. **模拟优先**：无 API 密钥时全流程用模拟适配器跑通，接入真实密钥即换
3. **逐镜生成**：系统设计层面不提供九宫格批量
4. **文档同步**：API 变更即时更新本计划与架构文档

# AI 漫剧工坊 · 前端 UI 设计规范

> 主题：**浅色日式治愈系（iyashikei）** —— 米白纸感底 + 暖沙灰阶 + 抹茶绿主色。
> 在线设计稿（可编辑）：https://ardot.tencent.com/file/714059025246017
> 导出图：`S1-首页-项目列表.png` / `S2-工作台-剧本工坊.png` / `S3-工作台-分镜车间.png` / `S4-设置页.png`（2x PNG）

## 1. 设计原则

- **平静设计（Calm Design）**：低饱和、柔和过渡、信息分级，降低创作工具长时间使用的视觉疲劳。
- **单一主行动**：每个页面/区块只有一个主按钮（抹茶绿实心），次级操作一律描边或文字链接。
- **状态全程可见**：任务队列、费用、失败重试、模拟模式降级都在界面上有明确反馈（对齐 BullMQ 任务模型）。
- **结构对应数据模型**：卡片与列表直接映射 Prisma 实体（Project / Character / Scene / Episode / Shot / GenTask / PromptTemplate），开发时可逐字段对照。

### 状态语义约定（与枚举对应）

- `ProjectStatus`：DRAFT 草稿=暖灰 / SCRIPTING·ASSETING·STORYBOARDING=天青 / RENDERING 合成中=暖杏 / DONE=苔绿
- `ShotStatus`：已确认/已出图=苔绿，出图中/生成中=暖杏，待确认=天青，失败=砖红
- `TaskStatus`：FAILED 一律砖红并给出「任务中心重试」入口

## 3. 字体与排版

- 全局字体：**Noto Sans SC**（思源黑体），实现侧沿用 Geist Sans 回退栈即可
- 页面标题 28 Bold / 区块标题 16 SemiBold / 卡片标题 13–14 SemiBold / 正文 12–13 Regular / 辅助 10–11 Regular
- 圆角体系：卡片 16 / 区块 14 / 小模块 12 / 输入框·按钮 10 / 徽章·进度条 999

## 4. 核心组件

| 组件 | 规格 |
|---|---|
| 主按钮 | 抹茶 `#5a7c4d` 实心 + 暖白文字 + 抹茶色柔阴影（y4/blur12/25%） |
| 次按钮 | 暖白底 + `#eae3d6` 描边 + 次要文字 |
| 状态徽章 | 语义色浅底 + 同色系深字，圆角 999，11px Medium |
| 项目卡 | 440 宽，含 状态徽章 / 梗概 / 四项统计（剧本·角色·场景·集数）/ 进度条 / 更新时间 |
| 四步步骤条 | 激活项淡抹茶底 + 抹茶描边 1.5；未激活暖白底浅沙描边 |
| 子步骤侧栏 | 完成=苔绿对勾 / 进行中=抹茶底+双环圆点 / 待办=灰色空心环 |
| 镜头卡 | 缩略图 16:9 + 镜头号·景别·运镜 + 台词（角色·情绪）+ 7 维提示词引用 + 操作链接 |
| 表单字段 | 标签 13 SemiBold + 暖纸底输入框（聚焦抹茶描边）+ 帮助/状态 11px |
| 保存栏 | 未保存变更摘要（暖杏）+ 放弃（描边）/ 保存 N 项变更（主按钮） |

## 5. 页面 ↔ 项目结构映射

| 设计页 | 路由 / 组件 | 覆盖流程 |
|---|---|---|
| S1 首页·项目列表 | `src/app/page.tsx` | 新建项目、项目网格（状态/统计/进度）、流水线引导 |
| S2 工作台·剧本工坊 | `src/app/projects/[id]/page.tsx` + `ScriptWorkbench` | 上传小说→提炼角色→分集大纲→分集剧本（三智能体），任务与费用卡 |
| S3 工作台·分镜车间 | `StoryboardWorkbench` | 剧集选择、镜头卡（景别/运镜/台词情绪/7 维提示词/资产引用）、批量出图、失败重试 |
| S4 设置页 | `src/app/settings/page.tsx` + `SettingsPanel` | 五分组 TABS（通用/文本/图像/视频/音频）、供应商密钥、温度参数、提示词模板、模拟模式提示、分组角标 + 「保存 N 项变更」 |

> 说明：资产工厂（M2）与视频合成厂（M4）界面复用 S2/S3 的同一套工作台骨架（步骤条 + 子步骤侧栏 + 主区卡片 + 底部翻页条），仅替换主区内容——资产工厂为「定妆照/空镜/道具」三标签资产卡（含一致性锁定态），视频合成厂为「成片预览 + 镜头配音/混音列表 + 导出分享」。
